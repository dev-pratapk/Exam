Formulation as a multistage problem

  • Stages: the three courses A, B, C (one stage per course).
  • State: d = number of study days still available (0 to 3).
  • Decision: number of days given to the course at that stage.
  • Return: the grade given by the table.

Let f1(d) = best total grade from course A alone with d days, f2(d) = best from A and B together, f3(d) = best from A, B and C together. The recursion (the principle of optimality) is

f1(d) = maxa ≤ d A(a)
f2(d) = maxb ≤ d [ B(b) + f1(d − b) ]
f3(d) = maxc ≤ d [ C(c) + f2(d − c) ]

Backward recovery of the plan

  1. Stage 3: best c = 2 days for course C, leaving 3 − 2 = 1 day.
  2. Stage 2 with d = 1: best b = 0 days for course B, leaving 1 day.
  3. Stage 1 with d = 1: a = 1 day for course A.

Total grade = A(1) + B(0) + C(2) = 1 + 1 + 3 = 5.

He should study course A for 1 day, course B for 0 days and course C for 2 days; the maximum total grade is 5.
