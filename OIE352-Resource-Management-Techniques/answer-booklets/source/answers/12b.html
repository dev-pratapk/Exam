Step 2: initial solution by Vogel's approximation method (VAM)

Penalty of a row (column) = difference between its two smallest costs. At each step the row or column with the largest penalty is selected and the smallest-cost cell in it is filled as much as possible; the exhausted row or column is deleted and the penalties are recalculated.

Step 3: optimality test by the MODI (u–v) method

For each occupied cell ui + vj = cij, with u1 = 0. For every empty cell the opportunity cost is Δij = cij − (ui + vj). The solution is optimal if all Δij ≥ 0.
