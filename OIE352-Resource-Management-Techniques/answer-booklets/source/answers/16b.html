Problem

Maximize Z = 80x1 + 45x2 subject to x1 + x2 ≤ 7, 12x1 + 5x2 ≤ 60, x1, x2 ≥ 0 and integers. (The constraint 12x1 + 5x2 ≤ 60 is used as in the 2020 paper; the 2021 paper prints 600, which would make this constraint useless.) I use the branch and bound method.

Step 1: LP relaxation

The corner points of the feasible region are (0, 0), (5, 0), (25/7, 24/7) and (0, 7). The two lines meet where x1 + x2 = 7 and 12x1 + 5x2 = 60, that is 7x1 = 25.

Corner(0, 0)(5, 0)(25/7, 24/7)(0, 7)

The LP optimum is Z = 440 at x1 = 25/7 ≈ 3.57, x2 = 24/7 ≈ 3.43. Both are fractional; 440 is an upper bound. Branch on x1.

All sub-problems are closed (integer, infeasible, or with bound not better than 420). The best integer solution is that of P1.

Check

(3, 4): 3 + 4 = 7 ≤ 7 and 12(3) + 5(4) = 56 ≤ 60. Trying the other integer points near the boundary, (4, 2) gives 410, (2, 5) gives 385 and (0, 7) gives 315, all below 420.

Optimum integer solution: x1 = 3, x2 = 4; maximum Z = 420.
