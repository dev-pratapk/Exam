Problem and Lagrange function

The Kuhn–Tucker (K–T) conditions are the necessary conditions for optimality of a non-linear programming problem with inequality constraints. Consider

Minimize f(X), X = (x1, …, xn), subject to gj(X) ≤ 0, j = 1, …, m.

Introduce a multiplier λj for each constraint and form the Lagrange function L(X, λ) = f(X) + Σj λj gj(X).

The conditions

If X* is a local minimum (and the constraints satisfy a regularity condition), there exist multipliers λj such that:

  1. Stationarity: ∂f/∂xi + Σj λj ∂gj/∂xi = 0 for i = 1, …, n.
  2. Complementary slackness: λj gj(X*) = 0. A constraint that is not active (gj < 0) has λj = 0.
  3. Feasibility: gj(X*) ≤ 0.
  4. Non-negativity of the multipliers: λj ≥ 0.

For a maximization problem (with gj ≤ 0) the stationarity condition becomes ∂f/∂xi − Σj λj ∂gj/∂xi = 0 with λj ≥ 0. The conditions are also sufficient when f is convex and every gj is convex (for minimization), since the problem is then a convex program.

Example

Minimize f = x12 + x22 subject to x1 + x2 ≥ 4, that is g = 4 − x1 − x2 ≤ 0.

L = x12 + x22 + λ(4 − x1 − x2)

The K–T conditions are

(1) ∂L/∂x1 = 2x1 − λ = 0
(2) ∂L/∂x2 = 2x2 − λ = 0
(3) λ(4 − x1 − x2) = 0
(4) x1 + x2 ≥ 4, λ ≥ 0
CaseWorkingResult
λ = 0 (constraint inactive)From (1) and (2): x1 = x2 = 0, but then x1 + x2 = 0 < 4Violates the constraint: rejected
g = 0 (constraint active)(1) and (2) give x1 = x2 = λ/2; the constraint 4 − x1 − x2 = 0 gives λ = 4, so x1 = x2 = 2λ = 4 ≥ 0: accepted

The function and the constraint are convex, so the K–T point is the global minimum. f* = 22 + 22 = 8.
