Converting the problem

The problem is: Minimize z = 2x1 + x2 with all constraints of the ≥ type. Write Z′ = −z (so we maximize Z′ = −2x1 − x2) and multiply each ≥ constraint by −1 to get ≤ constraints, then add slack variables:

−3x1 − x2 + s1 = −3
−4x1 − 3x2 + s2 = −6
−x1 − 2x2 + s3 = −3

The starting basic solution is s1 = −3, s2 = −6, s3 = −3. It is infeasible (negative right-hand sides) but optimal (all Cj − Zj ≤ 0), which is the situation for the dual simplex method.

Dual simplex iterations

Rule: (1) the leaving variable is the basic variable with the most negative RHS; (2) the entering variable is found by the minimum of |Cj − Zj| / |arj| over the negative entries arj of the leaving row; (3) stop when all RHS ≥ 0.

Solution

All the right-hand sides are now non-negative and all Cj − Zj ≤ 0, so the solution is optimal and feasible: x1 = 3/5, x2 = 6/5. Z′max = −12/5, so zmin = 12/5.
