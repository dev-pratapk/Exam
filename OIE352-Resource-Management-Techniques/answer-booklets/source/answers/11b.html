Standard form (Big-M method)

The first two constraints are of the ≤ type, so add slack variables s1, s2. The third is of the ≥ type, so subtract a surplus variable s3 and add an artificial variable a3, which is penalised with a very large cost −M in the objective.

Maximize Z = 2x1 + x2 + x3 + 0s1 + 0s2 + 0s3 − M a3
4x1 + 6x2 + 3x3 + s1 = 8
3x1 − 6x2 − 4x3 + s2 = 1
2x1 + 3x2 − 5x3 − s3 + a3 = 4

The initial basic feasible solution is s1 = 8, s2 = 1, a3 = 4.

Solution

In the last table every Cj − Zj ≤ 0, so the solution is optimal. The artificial variable a3 is zero (it remains in the basis at zero level), so the solution is feasible for the original problem. x1 = 9/7, x2 = 10/21, x3 = 0.
