Newton–Raphson method

To solve f(x) = 0, start from an initial guess x0 and improve it repeatedly using the tangent to the curve:

xn+1 = xn − f(xn) / f′(xn)

Given

f(x) = 2x3 − 2.5x − 5, f′(x) = 6x2 − 2.5, f″(x) = 12x. The root lies in [1, 2].

Initial guess

f(1) = 2 − 2.5 − 5 = −5.5 (negative) and f(2) = 16 − 5 − 5 = 6 (positive), so a root exists between 1 and 2. For guaranteed convergence start at the end where f(x0) and f″(x0) have the same sign: f(2) = 6 > 0 and f″(2) = 24 > 0, so take x0 = 2.
