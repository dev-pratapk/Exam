(i) Critical path method (CPM) and its usefulness (5 marks)

The critical path method is a project-scheduling technique that represents a project as a network of activities with their durations and precedence relations. A forward pass gives the earliest start and finish times and a backward pass gives the latest times; the critical path is the longest path from start to finish and gives the minimum project duration. The activities on it have zero total float.

Usefulness:

  • It gives the minimum project completion time and identifies the critical activities that need close control.
  • It shows the float (slack) of non-critical activities, so resources can be shifted to critical work.
  • It supports planning, scheduling and monitoring, and helps to see the effect of a delay on the completion date.
  • With activity costs it allows time–cost trade-off (crashing) and resource levelling.

(ii) Network diagram with two dummy activities (8 marks)

Rules: each activity is an arrow between two numbered events; an activity can start only when all its predecessors have finished; two activities may not share the same pair of events; a dummy activity (dashed arrow, zero duration) shows a precedence without consuming time.

Where dummies are needed:

  • D needs A and C but E needs only A. A ends at event 3, so E starts at event 3. C ends at event 4 and D starts at event 4. Dummy 3 → 4 makes A a predecessor of D.
  • H needs only G, but J and K need G and I. G ends at event 7, so H starts at event 7. Dummy 7 → 9 makes G a predecessor of J and K, which start at event 9 where I also ends.
