Formulation

Let x1 = number of trucks and x2 = number of automobiles produced per week.

Maximize Z = 300x1 + 200x2

subject to

5x1 + 2x2 ≤ 180 (shop A, man-days)
3x1 + 3x2 ≤ 135 (shop B, man-days), that is x1 + x2 ≤ 45
x1, x2 ≥ 0

Graphical solution

  1. Plot 5x1 + 2x2 = 180 through (36, 0) and (0, 90).
  2. Plot x1 + x2 = 45 through (45, 0) and (0, 45).
  3. Both constraints are of the ≤ type and x1, x2 ≥ 0, so the feasible region is the shaded polygon OABC.
  4. The corner B is the intersection of the two lines: 5x1 + 2(45 − x1) = 180 gives 3x1 = 90, x1 = 30, x2 = 15.

Value of Z at the corner points

Corner point(x1, x2)Z = 300x1 + 200x2
O(0, 0)0
A(36, 0)10 800
B(30, 15)9 000 + 3 000 = 12 000
C(0, 45)9 000

The maximum value of Z is at B.

Produce 30 trucks and 15 automobiles per week; the maximum profit is ₹12,000 per week.
