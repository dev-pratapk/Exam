Variance of the project time

σ2 = σ2(1–3) + σ2(3–5) + σ2(5–6) = 1 + 4 + 4 = 9, so σ = 3 weeks

(iv) Probability of finishing at least 3 weeks earlier than expected

T = 17 − 3 = 14 weeks. Z = (T − TE)/σ = (14 − 17)/3 = −1.

P(T ≤ 14) = P(Z ≤ −1) = 1 − 0.8413 = 0.1587 ≈ 15.9 %
