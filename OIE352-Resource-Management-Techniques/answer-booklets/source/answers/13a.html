Problem

Minimize Z = −2x1 − 3x2 subject to 2x1 + 2x2 ≤ 7, x1 ≤ 2, x2 ≤ 2, x1, x2 ≥ 0 and integers. Equivalent: maximize Z′ = 2x1 + 3x2 with x1 + x2 ≤ 3.5 (Z = −Z′). I use the branch and bound method.

Step 1: LP relaxation (ignore integrality)

The feasible region is the polygon bounded by x1 ≤ 2, x2 ≤ 2, x1 + x2 ≤ 3.5. Its corner points are (0, 0), (2, 0), (2, 1.5), (1.5, 2) and (0, 2). Since x2 has the larger profit, the maximum is at (1.5, 2):

Z′ = 2(1.5) + 3(2) = 9, so Z = −9 (a lower bound for the minimum).

x1 = 1.5 is not an integer, so branch on x1.

Check

(1, 2): 2(1) + 2(2) = 6 ≤ 7, x1 = 1 ≤ 2, x2 = 2 ≤ 2. Other feasible integer points give Z = 0, −2, −3, −4, −6, −7, so −8 is the minimum.

Optimum integer solution: x1 = 1, x2 = 2; minimum Z = −8.
