Given / To prove

Given: A chain (L, ≤), that is, a partially ordered set in which every two elements are comparable. To prove: L is a distributive lattice — first that every pair of elements has a meet (glb) and a join (lub), and then that the distributive law holds.

Definitions used

  • Chain (totally ordered set): a poset (L, ≤) in which, for all a, b ∈ L, either a ≤ b or b ≤ a.
  • Lattice: a poset in which every pair a, b has a greatest lower bound a ∧ b (the meet) and a least upper bound a ∨ b (the join).
  • Distributive lattice: a lattice in which meet distributes over join,
    a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c) for all a, b, c ∈ L.

Part 1: Every chain is a lattice

Let a, b ∈ L. Since L is a chain, either a ≤ b or b ≤ a.

  1. Case a ≤ b. Then a is a lower bound of {a, b} and b is an upper bound. Any lower bound x must satisfy x ≤ a (because a is one of the two elements), so a is the greatest lower bound: a ∧ b = a. Likewise every upper bound x satisfies b ≤ x, so b is the least upper bound: a ∨ b = b.
  2. Case b ≤ a. The same reasoning, with a and b interchanged, gives a ∧ b = b and a ∨ b = a.

Hence in a chain the meet is the smaller element and the join is the larger element:

a ∧ b = min(a, b),    a ∨ b = max(a, b).

Since a ∧ b and a ∨ b exist for every pair a, b, the chain L is a lattice.

Part 2: The lattice is distributive

Let a, b, c ∈ L. We prove a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c). Since L is a chain, b and c are comparable, and for each pair the meet is the minimum and the join is the maximum. Two cases arise.

Case 1: b ≤ c. Then b ∨ c = c, and a is comparable with both.

Position of aa ∧ (b ∨ c)(a ∧ b) ∨ (a ∧ c)
a ≤ b (so a ≤ b ≤ c)a ∧ c = aa ∨ a = a
b ≤ a ≤ ca ∧ c = ab ∨ a = a
c ≤ aa ∧ c = cb ∨ c = c

Both sides agree in every sub-case.

Case 2: c ≤ b. Then b ∨ c = b.

Position of aa ∧ (b ∨ c)(a ∧ b) ∨ (a ∧ c)
a ≤ c (so a ≤ c ≤ b)a ∧ b = aa ∨ a = a
c ≤ a ≤ ba ∧ b = aa ∨ c = a
b ≤ aa ∧ b = bb ∨ c = b

Again both sides agree. In every case a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c).

The dual law a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c) now follows by the principle of duality (interchange ∧ with ∨ and ≤ with ≥ throughout). Hence the lattice is distributive.

Therefore every chain is a distributive lattice. ∎

Given / To prove

Given: A distributive complemented lattice (L, ∧, ∨, ′, 0, 1). For x ∈ L, let x′ denote the complement of x (the bar notation x̄), so that

x ∧ x′ = 0,    x ∨ x′ = 1.

To prove: for any a, b ∈ L the following four statements are equivalent:

  1. a ≤ b
  2. a ∧ b′ = 0
  3. a′ ∨ b = 1
  4. b′ ≤ a′

Definitions and results used

  • Complement laws: x ∧ x′ = 0, x ∨ x′ = 1; also 0′ = 1, 1′ = 0.
  • Bounded identities: x ∧ 0 = 0, x ∧ 1 = x, x ∨ 0 = x, x ∨ 1 = 1.
  • Uniqueness of complement (in a distributive lattice), together with the consequences (x′)′ = x and De Morgan's laws
    (x ∧ y)′ = x′ ∨ y′,    (x ∨ y)′ = x′ ∧ y′.

Lemma: complements are unique

Suppose x has two complements y and z. Then

y = y ∧ 1 = y ∧ (x ∨ z) = (y ∧ x) ∨ (y ∧ z) = 0 ∨ (y ∧ z) = y ∧ z,

so y ≤ z. Interchanging y and z gives z ≤ y. Hence y = z. Therefore each element has exactly one complement, and x is the unique complement of x′, so (x′)′ = x. Applying uniqueness to the element x ∧ y shows that x′ ∨ y′ is its complement, which is De Morgan's first law; the second is dual.

Proof of the equivalences

We prove the cycle of implications (1) ⇒ (2) ⇒ (3) ⇒ (4) ⇒ (1). Each step uses distributivity, the complement laws and uniqueness of complement.

(1) ⇒ (2). Assume a ≤ b. Then a ∧ b = a, and

a ∧ b′ = (a ∧ b) ∧ b′ = a ∧ (b ∧ b′) = a ∧ 0 = 0.

(2) ⇒ (3). Assume a ∧ b′ = 0. Taking complements and using De Morgan's law and (b′)′ = b,

a′ ∨ b = a′ ∨ (b′)′ = (a ∧ b′)′ = 0′ = 1.

(3) ⇒ (4). Assume a′ ∨ b = 1. Then

b′ = b′ ∧ 1 = b′ ∧ (a′ ∨ b) = (b′ ∧ a′) ∨ (b′ ∧ b) = (b′ ∧ a′) ∨ 0 = b′ ∧ a′.

Since b′ = b′ ∧ a′, b′ is a lower bound of a′, that is, b′ ≤ a′.

(4) ⇒ (1). Assume b′ ≤ a′. Then a ∧ b′ is a lower bound of both a and a′, so

a ∧ b′ ≤ a ∧ a′ = 0, hence a ∧ b′ = 0.

Now

a = a ∧ 1 = a ∧ (b ∨ b′) = (a ∧ b) ∨ (a ∧ b′) = (a ∧ b) ∨ 0 = a ∧ b,

and a = a ∧ b means a ≤ b.

Thus (1) ⇒ (2) ⇒ (3) ⇒ (4) ⇒ (1). Since the last statement implies the first, all four statements imply one another and are therefore equivalent.

Hence in a distributive complemented lattice, a ≤ b ⇔ a ∧ b′ = 0 ⇔ a′ ∨ b = 1 ⇔ b′ ≤ a′. ∎
