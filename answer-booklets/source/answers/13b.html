Statement (Dirac's theorem)

If G is a connected simple graph with n vertices, where n ≥ 3, such that deg(v) ≥ n/2 for every vertex v of G, then G has a Hamilton cycle (a cycle containing every vertex of G exactly once).

Given: G is connected and simple, |V(G)| = n ≥ 3, and deg(v) ≥ n/2 for all v ∈ V(G). To prove: G contains a Hamilton cycle.

Definitions used

  • Simple graph: an undirected graph with no loops and no multiple edges.
  • Degree deg(v): the number of edges incident with v.
  • Path / cycle: a path is a sequence of distinct vertices in which consecutive vertices are joined by an edge; a cycle is a path together with the edge joining its last vertex back to its first.
  • Hamilton cycle: a cycle that passes through all the n vertices of G.
  • Longest path: a simple path of G having the largest possible number of vertices.

Proof (longest-path argument)

  1. Among all simple paths of G choose one with the maximum number of vertices,
    P : v1, v2, …, vk,    k ≤ n.
    Since n ≥ 3 gives deg(v) ≥ n/2 ≥ 1.5, every degree is an integer at least 2; hence G contains a cycle and the longest path has k ≥ 3.
  2. Every neighbour of v1 and of vk lies on P. If some neighbour w of v1 were outside P, then w, v1, v2, …, vk would be a path with k + 1 vertices, contradicting the maximality of k. The same argument applies to vk. Hence
    N(v1) ⊆ { v2, …, vk },    N(vk) ⊆ { v1, …, vk−1 }.
  3. Two index sets. Define
    A = { i : 1 ≤ i ≤ k−1 and v1 is adjacent to vi+1 },
    B = { i : 1 ≤ i ≤ k−1 and vk is adjacent to vi }.
    By step 2 the map vi+1 ↔ i is a bijection from N(v1) onto A, so |A| = deg(v1) ≥ n/2; similarly |B| = deg(vk) ≥ n/2.
  4. A and B meet. Both A and B are subsets of { 1, 2, …, k−1 }, a set with k−1 ≤ n−1 elements. If A ∩ B = ∅, then
    |A| + |B| ≤ k − 1 ≤ n − 1 < n,
    which contradicts |A| + |B| ≥ n/2 + n/2 = n. Therefore A ∩ B ≠ ∅; choose i ∈ A ∩ B.
  5. Close P into a cycle. For this i, v1 is adjacent to vi+1 (since i ∈ A) and vk is adjacent to vi (since i ∈ B). Hence
    C : v1, v2, …, vi, vk, vk−1, …, vi+1, v1
    is a cycle: consecutive vertices are joined along P, by the edge vivk, backwards along P, and by the edge vi+1v1. It contains exactly the k vertices of P.
  6. P uses all vertices. Suppose k < n. Then some vertex of G lies outside C. Since G is connected, a shortest path from such a vertex to C ends with an edge x′ y where x′ ∉ V(C) and y ∈ V(C). Start at x′, move to y, and then go once completely around C; this is a simple path with k + 1 vertices, contradicting the maximality of k. Hence k = n.
  7. Conclusion. The cycle C now contains all n vertices of G, so C is a Hamilton cycle.
Hence every connected simple graph G with n ≥ 3 and deg(v) ≥ n/2 for every vertex v has a Hamilton cycle (Dirac's theorem). ∎

Euler's theorem (criterion used)

For a connected graph: (1) an Euler circuit (a closed trail using every edge exactly once) exists ⇔ every vertex has even degree; (2) an Euler path (an open trail using every edge exactly once) exists ⇔ the graph has exactly two vertices of odd degree, and the path starts at one odd vertex and ends at the other. If there are more than two odd-degree vertices, neither an Euler path nor an Euler circuit exists.
