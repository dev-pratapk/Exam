Problem

Given: The non-homogeneous linear recurrence relation with constant coefficients

T(k) − 7T(k − 1) + 10T(k − 2) = 6 + 8k,   k ≥ 2,

with the initial conditions T(0) = 1, T(1) = 2. To find: the solution T(k) for all k ≥ 0.

The general solution has the form T(k) = Th(k) + Tp(k), where Th is the solution of the associated homogeneous equation and Tp is any particular solution of the given equation.

Step 1: Homogeneous solution Th(k)

The associated homogeneous equation is T(k) − 7T(k − 1) + 10T(k − 2) = 0. Its characteristic equation is

r2 − 7r + 10 = 0  ⇒  (r − 2)(r − 5) = 0,

so the roots are r1 = 2 and r2 = 5, distinct. Hence, with arbitrary constants A and B,

Th(k) = A · 2k + B · 5k.

Step 2: Particular solution Tp(k)

The right-hand side is the linear function 6 + 8k, and 1 is not a characteristic root. Therefore we try a particular solution of the same linear form

Tp(k) = ck + d,

where c and d are constants to be determined. Substituting into the recurrence,

Tp(k) − 7Tp(k − 1) + 10Tp(k − 2)
= (ck + d) − 7[c(k − 1) + d] + 10[c(k − 2) + d]
= ck + d − 7ck + 7c − 7d + 10ck − 20c + 10d
= (c − 7c + 10c)k + (d − 7d + 10d) + (7c − 20c)
= 4c·k + (4d − 13c).

This must equal 6 + 8k for all k. Comparing coefficients of k and the constant terms:

4c = 8  ⇒  c = 2,     4d − 13c = 6  ⇒  4d − 26 = 6  ⇒  d = 8.

Thus the particular solution is

Tp(k) = 2k + 8.

Step 3: General solution and evaluation of the constants

Adding the two parts, the general solution is

T(k) = A · 2k + B · 5k + 2k + 8.

Apply T(0) = 1:

A + B + 8 = 1  ⇒  A + B = −7  … (1)

Apply T(1) = 2:

2A + 5B + 2 + 8 = 2  ⇒  2A + 5B = −8  … (2)

From (1), A = −7 − B. Substituting in (2):

2(−7 − B) + 5B = −8  ⇒  −14 − 2B + 5B = −8  ⇒  3B = 6  ⇒  B = 2.

Then A = −7 − 2 = −9.

Step 4: Solution and verification

Therefore

T(k) = −9 · 2k + 2 · 5k + 2k + 8.

Check. T(2) = −9(4) + 2(25) + 4 + 8 = −36 + 50 + 12 = 26 and T(3) = −9(8) + 2(125) + 6 + 8 = −72 + 250 + 14 = 192. Also T(2) − 7T(1) + 10T(0) = 26 − 14 + 10 = 22 = 6 + 8(2), which satisfies the relation.

T(k) = −9 · 2k + 2 · 5k + 2k + 8,   k ≥ 0.

Problem

Given: The integers 1, 2, 3, …, 250. To find: how many of them are not divisible by any of the integers 2, 3, 5, 7.

Let the universal set be U = {1, 2, …, 250}, so |U| = 250. Define the four sets

A2 = {n ∈ U : 2 | n},   A3 = {n ∈ U : 3 | n},   A5 = {n ∈ U : 5 | n},   A7 = {n ∈ U : 7 | n}.

We require the number of integers divisible by at least one of 2, 3, 5, 7, that is |A2 ∪ A3 ∪ A5 ∪ A7|; the required answer is 250 minus this count.

Method: Principle of Inclusion–Exclusion

For four sets the principle states

|A2 ∪ A3 ∪ A5 ∪ A7| = Σ|Ai| − Σ|Ai ∩ Aj| + Σ|Ai ∩ Aj ∩ Ak| − |A2 ∩ A3 ∩ A5 ∩ A7|.

The number of integers in U divisible by both a and b is the number divisible by lcm(a, b), namely ⌊250 / lcm(a, b)⌋; similarly for three or four integers.

Step 1: Sum of single counts

|A2| = ⌊250/2⌋ = 125,   |A3| = ⌊250/3⌋ = 83,   |A5| = ⌊250/5⌋ = 50,   |A7| = ⌊250/7⌋ = 35.
Σ|Ai| = 125 + 83 + 50 + 35 = 293.

Step 2: Sum of pairwise intersections

PairlcmCount
2, 36⌊250/6⌋ = 41
2, 510⌊250/10⌋ = 25
2, 714⌊250/14⌋ = 17
3, 515⌊250/15⌋ = 16
3, 721⌊250/21⌋ = 11
5, 735⌊250/35⌋ = 7
Σ|Ai ∩ Aj| = 41 + 25 + 17 + 16 + 11 + 7 = 117.

Step 3: Sum of triple intersections

TriplelcmCount
2, 3, 530⌊250/30⌋ = 8
2, 3, 742⌊250/42⌋ = 5
2, 5, 770⌊250/70⌋ = 3
3, 5, 7105⌊250/105⌋ = 2
Σ|Ai ∩ Aj ∩ Ak| = 8 + 5 + 3 + 2 = 18.

Step 4: Fourfold intersection and result

|A2 ∩ A3 ∩ A5 ∩ A7| = ⌊250/210⌋ = 1.

Therefore the number of integers divisible by at least one of 2, 3, 5, 7 is

293 − 117 + 18 − 1 = 193.

Hence the number of integers not divisible by any of 2, 3, 5, 7 is

250 − 193 = 57.
Number of integers between 1 and 250 not divisible by any of 2, 3, 5, 7 = 57.
