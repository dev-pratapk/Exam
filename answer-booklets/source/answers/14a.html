Lagrange's Theorem

Statement. Let ⟨G, *⟩ be a finite group and let H be a subgroup of G. Then the order of H divides the order of G; that is, |H| divides |G|. Equivalently, |G| = |H| · [G : H], where [G : H] is the number of distinct left cosets of H in G (called the index of H in G).

Definitions used

  • Order of a group G, denoted |G|, is the number of elements in G.
  • For a ∈ G, the left coset of H determined by a is aH = {a * h : h ∈ H}.
  • The index [G : H] is the number of distinct left cosets of H in G.

Proof

Let the distinct left cosets of H in G be a1H, a2H, …, akH. We establish the following facts about these cosets.

  1. Every element of G lies in some left coset. For any a ∈ G, since the identity e ∈ H we have a = a * e ∈ aH. Hence
    G = a1H ∪ a2H ∪ … ∪ akH.
  2. Distinct left cosets are disjoint. Suppose aH ∩ bH ≠ ∅, say x ∈ aH ∩ bH. Then x = a * h1 = b * h2 for some h1, h2 ∈ H, so a = b * h2 * h1−1. For any a * h ∈ aH,
    a * h = (b * h2 * h1−1) * h = b * (h2 * h1−1 * h) ∈ bH,
    since h2 * h1−1 * h ∈ H (H is closed). Thus aH ⊆ bH, and similarly bH ⊆ aH. Hence aH = bH. Therefore any two left cosets are either identical or disjoint.
  3. Every left coset has exactly |H| elements. Define φ : H → aH by φ(h) = a * h. It is surjective by the definition of aH. If φ(h1) = φ(h2), then a * h1 = a * h2, and left cancellation gives h1 = h2; so φ is injective. Hence φ is a bijection and |aH| = |H| for every a ∈ G.
  4. Counting the elements of G. By steps 1 and 2 the k distinct left cosets partition G, and by step 3 each contains |H| elements. Therefore
    |G| = |a1H| + |a2H| + … + |akH| = k · |H| = [G : H] · |H|.

Since k = [G : H] is a positive integer, |H| divides |G|. In particular, if G is a finite group and a ∈ G, then the order of the cyclic subgroup ⟨a⟩ (which equals the order of the element a) divides |G|.

Hence |G| = [G : H] · |H|, so the order of every subgroup of a finite group divides the order of the group. ∎

Problem

Given: A homomorphism f : ⟨G, *⟩ → ⟨H, Δ⟩ of groups, with identity elements eG ∈ G and eH ∈ H. The kernel of f is K = Ker f = {x ∈ G : f(x) = eH}. To prove: K is a normal subgroup of ⟨G, *⟩.

Working fact. For any homomorphism f and any a ∈ G, f(a−1) = (f(a))−1.

Part 1: K is a subgroup of G

  1. K is non-empty. Since f preserves identity, f(eG) = eH, so eG ∈ K.
  2. K is closed under *. Let a, b ∈ K. Then f(a) = f(b) = eH, and since f is a homomorphism,
    f(a * b) = f(a) Δ f(b) = eH Δ eH = eH,
    so a * b ∈ K.
  3. K contains inverses. Let a ∈ K. Then
    f(a−1) = (f(a))−1 = eH−1 = eH,
    so a−1 ∈ K.

Thus K is a non-empty subset of G that is closed under the operation and under inverses. Hence K is a subgroup of G.

Part 2: K is normal in G

A subgroup N of G is normal if a * x * a−1 ∈ N for all a ∈ G and all x ∈ N (equivalently, aN = Na). Let x ∈ K and a ∈ G. Using the homomorphism property and f(a−1) = (f(a))−1,

f(a * x * a−1) = f(a) Δ f(x) Δ f(a−1) = f(a) Δ eH Δ (f(a))−1 = f(a) Δ (f(a))−1 = eH.

Hence a * x * a−1 ∈ K for every x ∈ K and every a ∈ G. That is, aKa−1 ⊆ K for all a ∈ G, which is precisely the condition that K is a normal subgroup of G.

Hence the kernel Ker f is a normal subgroup of ⟨G, *⟩. Thus the kernel of every group homomorphism is a normal subgroup. ∎
