Problem

To prove: for every positive integer n,

P(n):   12 + 22 + 32 + ⋯ + n2 = n(n + 1)(2n + 1) / 6.

Method: the Principle of Mathematical Induction (weak induction). If a statement P(n) satisfies (I) P(1) is true, and (II) P(k) true ⇒ P(k + 1) true for every k ≥ 1, then P(n) is true for all positive integers n.

Step 1: Basis of induction (n = 1)

LHS = 12 = 1. RHS = 1 · (1 + 1) · (2 · 1 + 1) / 6 = 1 · 2 · 3 / 6 = 1. Since LHS = RHS, P(1) is true. Hence the basis is verified.

Step 2: Inductive hypothesis

Assume that the result is true for some positive integer k ≥ 1, that is,

P(k):   12 + 22 + ⋯ + k2 = k(k + 1)(2k + 1) / 6.

Step 3: Inductive step — proof of P(k + 1)

We must show that

12 + 22 + ⋯ + k2 + (k + 1)2 = (k + 1)(k + 2)(2k + 3) / 6.

Now, splitting off the last term and using the inductive hypothesis P(k),

12 + ⋯ + k2 + (k + 1)2 = k(k + 1)(2k + 1)/6 + (k + 1)2
= (k + 1) [ k(2k + 1)/6 + (k + 1) ]    (taking (k + 1) common)
= (k + 1) [ k(2k + 1) + 6(k + 1) ] / 6
= (k + 1) [ 2k2 + k + 6k + 6 ] / 6
= (k + 1)(2k2 + 7k + 6) / 6.

Factorising the quadratic: 2k2 + 7k + 6 = 2k2 + 4k + 3k + 6 = 2k(k + 2) + 3(k + 2) = (k + 2)(2k + 3). Hence

12 + ⋯ + k2 + (k + 1)2 = (k + 1)(k + 2)(2k + 3) / 6.

But this is exactly the statement P(k + 1), because replacing n by k + 1 in n(n + 1)(2n + 1)/6 gives (k + 1)(k + 2)(2(k + 1) + 1)/6 = (k + 1)(k + 2)(2k + 3)/6. Thus P(k) ⇒ P(k + 1).

Step 4: Conclusion

Both conditions of the Principle of Mathematical Induction are satisfied: P(1) is true, and P(k) ⇒ P(k + 1) for every k ≥ 1. Therefore P(n) is true for all positive integers n.

Check for n = 2: LHS = 1 + 4 = 5, RHS = 2 · 3 · 5 / 6 = 5. n = 3: LHS = 5 + 9 = 14, RHS = 3 · 4 · 7 / 6 = 14. ✓

Hence 12 + 22 + 32 + ⋯ + n2 = n(n + 1)(2n + 1)/6 for every positive integer n. ∎

Problem

To prove: if n is an integer greater than 1, then n can be written as a product of primes.

Note on meaning. A prime is an integer p > 1 whose only positive divisors are 1 and p. “A product of primes” includes the case of a single factor, so every prime is a product of primes (with one factor). Repeated primes are allowed, and the order of the factors is irrelevant.

Method: the Second (Strong) Principle of Induction. If a statement P(n) satisfies (I) P(2) is true, and (II) for every k ≥ 2, the truth of P(2), P(3), …, P(k) together implies P(k + 1), then P(n) is true for all integers n ≥ 2.

Step 1: Basis of induction (n = 2)

Here P(n) is the statement “n is a product of primes”. The integer 2 is prime, so 2 is a product of primes (a single factor). Hence P(2) is true.

Step 2: Inductive hypothesis

Assume that for some integer k ≥ 2, every integer j with 2 ≤ j ≤ k can be written as a product of primes. That is, P(2), P(3), …, P(k) are all true.

Step 3: Inductive step — proof of P(k + 1)

Consider the integer k + 1. Since k ≥ 2, we have k + 1 ≥ 3 > 1, so exactly one of the following two cases occurs.

Case 1: k + 1 is prime. Then k + 1 is itself a prime, hence a product of primes (with the single factor k + 1). So P(k + 1) holds.

Case 2: k + 1 is composite. Then by the definition of a composite number,

k + 1 = a · b    for some integers a, b with 1 < a ≤ b < k + 1.

Thus 2 ≤ a ≤ k and 2 ≤ b ≤ k. By the inductive hypothesis, both a and b are products of primes:

a = p1 p2 ⋯ pr,     b = q1 q2 ⋯ qs,

where each pi and each qj is prime. Multiplying,

k + 1 = a · b = p1 p2 ⋯ pr q1 q2 ⋯ qs,

which is a product of the primes p1, …, pr, q1, …, qs. So P(k + 1) holds in this case also.

In both cases k + 1 is a product of primes. Hence the truth of P(2), …, P(k) implies the truth of P(k + 1).

Step 4: Conclusion

Conditions (I) and (II) of the strong induction principle are satisfied, so P(n) is true for every integer n ≥ 2. That is, every integer n greater than 1 can be written as a product of primes.

Illustration. 12 = 2 · 2 · 3, 91 = 7 · 13, 97 is prime, 360 = 23 · 32 · 5 — each is a product of primes, as the proof guarantees.

Hence every integer n > 1 can be written as a product of primes. ∎
