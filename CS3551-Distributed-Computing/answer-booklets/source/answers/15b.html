Introduction

Cloud computing delivers resources as services over a network. The services are organized in three service models, each built on the one below it, and each cloud platform (Amazon Web Services, Google Cloud Platform, Microsoft Azure) offers many services of each kind.

1. Cloud service models

ModelWhat the provider givesUser managesExamples
IaaSVirtual machines, storage, networksOS, middleware, runtime, application, dataAmazon EC2 and S3, Google Compute Engine, Azure Virtual Machines
PaaSPlatform to build and run applications: runtime, frameworks, databasesApplication and data onlyGoogle App Engine, AWS Elastic Beanstalk, Azure App Service
SaaSComplete application delivered through a browserOnly use and configurationGmail, Salesforce, Microsoft 365, Google Workspace

  • Compute services provide virtual machines that can be created, resized and stopped on demand (pay per hour or second).
  • Storage services provide scalable, durable storage for objects and files, accessed through web APIs.
  • Database services provide managed relational (SQL) and NoSQL databases; the provider handles backup, patching and replication.
  • Application services provide ready-made building blocks for applications: application runtimes and frameworks, message queues, e-mail and notification services, content delivery networks, MapReduce, media transcoding and search.

3. Example of an application service adapted by an organization (illustrative)

An online retailer runs its shop on the cloud:

  1. The web application runs on a PaaS runtime (for example Elastic Beanstalk or App Engine) that scales automatically on sale days.
  2. Each order is placed on a message queue (Amazon SQS). Worker processes read the queue, so a burst of orders does not overload the system.
  3. After processing, an e-mail service (Amazon SES) sends the order confirmation and a notification service (Amazon SNS) sends an SMS or push message.
  4. Product images are stored in object storage (S3) and delivered quickly through a content delivery network (CloudFront); orders are kept in a managed database (RDS).

The retailer pays only for what it uses, has no servers to maintain, and can handle peak load by scaling these services.

Hence cloud services are delivered as IaaS, PaaS and SaaS, and platforms such as AWS, Google Cloud Platform and Azure supply the compute, storage, database and application services that organizations adapt to build their applications.
