Introduction

A global state of a distributed system is the collection of the local states of all processes and the states of all communication channels. There is no shared memory and no global clock, so no process can look at the whole system at one instant. A snapshot algorithm therefore records a global state that is consistent.

Let LSi be the local state of process pi and SCij the state of channel Cij, that is, the messages sent by pi but not yet received by pj.

GS = { ∪i LSi , ∪i,j SCij }
SCij = { mij | send(mij) ∈ LSi ∧ rec(mij) ∉ LSj }

Needs of a snapshot

  • Checkpointing and recovery: after a failure the system restarts from a recorded consistent state.
  • Deadlock detection: a cycle is searched for in the recorded wait-for graph.
  • Termination detection: the computation has terminated if all processes are passive and all channels are empty in the recorded state.
  • Garbage collection: objects that are unreachable in the recorded state can be removed.
  • Debugging and monitoring: global predicates and breakpoints are evaluated on a consistent state.

Consistent global state

A recorded global state is consistent if it satisfies two conditions for every message mij:

  1. C1: send(mij) ∈ LSi ⇒ mij ∈ SCij ⊕ rec(mij) ∈ LSj. A message that is recorded as sent is either in the channel state or already received, exactly one of the two.
  2. C2: send(mij) ∉ LSi ⇒ mij ∉ SCij ∧ rec(mij) ∉ LSj. A message that is not recorded as sent can be neither in the channel nor received.

So the state has no orphan message (received but not sent) and no lost message (sent but nowhere recorded).

Chandy–Lamport snapshot algorithm

Assumptions: channels are FIFO and reliable; the network is strongly connected; processes do not fail; the application keeps running during the snapshot; any process may initiate. A special control message called a marker is used. In a FIFO channel the marker separates the messages sent before the sender recorded its state from those sent after.

Marker Sending Rule for process pi

  1. pi records its state.
  2. For each outgoing channel C on which a marker has not been sent, pi sends a marker along C before it sends any further message along C.

Marker Receiving Rule for process pj on receiving a marker along channel C

ConditionAction
pj has not recorded its stateRecord the state of C as the empty set; then execute the Marker Sending Rule.
pj has already recorded its stateRecord the state of C as the set of messages received along C after pj’s state was recorded and before pj received the marker along C.

Termination: the algorithm ends at a process when it has received a marker on every incoming channel. The recorded local and channel states are then sent to the initiator, for example by flooding, which assembles the global state.

Illustration

Two processes P1 and P2 are connected by channels C12 (P1 to P2) and C21 (P2 to P1). They hold account balances: P1 has ₹500 and P2 has ₹300, so the total is ₹800.

TimeEvent
t1P2 sends message m (transfer of ₹100) to P1; P2’s balance becomes 200.
t2P1 initiates the snapshot: it records LS1 = 500 and sends a marker on C12.
t3P2 receives the marker on C12 for the first time: it records LS2 = 200, sets SC12 = { } and sends a marker on C21 (after m, because the channel is FIFO).
t4P1 receives m (its balance becomes 600). P1 has already recorded its state and has not yet received the marker on C21, so m belongs to the channel state.
t5P1 receives the marker on C21: it records SC21 = {m}. Every process has now received a marker on all incoming channels, so the snapshot is complete.

Recorded global state: LS1 = 500, LS2 = 200, SC12 = { }, SC21 = {₹100 in transit}. Total = 500 + 200 + 0 + 100 = ₹800, equal to the true total, so no money is lost or created. The state satisfies C1 and C2: m was sent before P2 recorded its state and received after P1 recorded its state, so it appears exactly once, in SC21.

Properties

  • The recorded state is consistent. It may not be a state that really occurred during the execution, but it is reachable from the initial state and the final state is reachable from it.
  • One marker is sent on each channel in each direction, so the message complexity is O(e) for e links. The time complexity is O(d), where d is the diameter of the network.
  • FIFO channels are essential. For non-FIFO channels other algorithms (for example Lai–Yang) are used.
Hence the Chandy–Lamport algorithm records a consistent global state using markers on FIFO channels, with O(e) messages and O(d) time.
