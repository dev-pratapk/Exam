Introduction

Mutual exclusion allows at most one process in its critical section (CS) at a time. Ricart–Agrawala (1981) is a fully distributed timestamp-based algorithm: a site enters the CS only after a REPLY from every other site and defers requests in an array instead of using a central queue.

System model and assumptions

  • There are N sites P1, …, PN; each site knows all the others.
  • Channels are reliable (Kshemkalyani and Singhal): no message is lost, duplicated or corrupted, and all are eventually delivered. Requests are totally ordered by (timestamp, site-id).
  • Each site has a Lamport clock: increment before sending a REQUEST; on receiving a message stamped tsj set tsi = max(tsi, tsj) + 1. Requests are ordered by (tsi, i).
  • CS execution time is finite.

Data structures and messages

  • REQUEST(tsi, i): multicast to all other N−1 sites.
  • REPLY(tsi): permission sent to a requester.
  • RDi[1…N]: request-deferred array; RDi[j] = 1 means j's request is deferred and a REPLY is owed to j, while RDi[i] = 1 marks i's own outstanding request. Initially all 0.
  • reply_counti: number of REPLYs received.

Algorithm at site Pi

(1) Requesting the CS

  1. Increment the clock: tsi = tsi + 1.
  2. Set RDi[i] = 1 and reply_counti = 0.
  3. Send REQUEST(tsi, i) to all other N−1 sites.

(2) On receiving REQUEST(tsj, j) — deferral rule

Defer ⇔ (i is executing the CS) ∨ (i is requesting ∧ (tsi, i) < (tsj, j))
  1. Update tsi = max(tsi, tsj) + 1.
  2. If the condition holds, set RDi[j] = 1; send no REPLY now.
  3. Otherwise send REPLY(tsi) to j immediately.

(3) Executing the CS: i enters only after REPLYs from all other N−1 sites (reply_counti = N−1); requests received in the CS are deferred by rule (2).

(4) Releasing the CS: on exit set RDi[i] = 0; for every j with RDi[j] = 1, send the deferred REPLY and clear RDi[j].

Correctness

Mutual exclusion. Suppose Pi and Pj are in the CS together, with (tsi, i) < (tsj, j). Pj must have received a REPLY from Pi. When Pi replied it was neither in the CS nor requesting with the smaller timestamp (else it would defer Pj), so Pi had not yet requested. But receiving Pj's REQUEST raises Pi's clock above tsj, so Pi's later request is younger and Pj defers it until exit — contradiction.

No starvation. The oldest outstanding request is deferred only by sites in the CS; any requesting site has a larger timestamp and replies at once. Since CS execution is finite, the oldest request gets all N−1 REPLYs and enters, and the argument repeats by induction. Once a request reaches all sites, clock updates make later requests younger, so no older request can appear indefinitely.

Performance

  • Message complexity: N−1 REQUESTs + N−1 REPLYs = 2(N−1) messages per CS entry.
  • Synchronization delay: T, one message transmission time.
  • No central coordinator, hence no single point of failure.

Conclusion

Ricart–Agrawala gives distributed mutual exclusion with 2(N−1) messages, delay T, and no starvation; Lamport needs 3(N−1).
